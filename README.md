# Smart Chef AI 👨‍🍳

An advanced, premium, and stunning AI-powered culinary companion that creates unique, detailed, and delicious recipes using the **Gemini 3 Flash API**.

## ✨ Features

- **Pantry Input:** Add ingredients easily via dynamic, styled tags.
- **🎲 Surprise Me:** Need inspiration? Click the Surprise Me button to instantly auto-populate creative ingredient suggestions.
- **Personalized Culinary Directives:** Customize your dish by Cuisine Style, Servings, and Dietary Restrictions.
- **Simulated Streaming/Typing Effect:** Watch as the recipe's title is visually typed on your screen, providing a luxurious experience.
- **Precise Recipe Generation:** Delivers structured data (ingredients with measurements, step-by-step cooking steps, and nutritional breakdown).
- **Glassmorphism Theme:** Beautiful, dark-mode, responsive UI built with glassmorphic elements and curated color tokens.

## 🚀 Tech Stack

- **Framework:** React 19 + Vite
- **AI API:** Google Gemini 3 Flash API (`gemini-3-flash-preview`)
- **Styling:** Vanilla CSS3 with bespoke dark mode and glassmorphism styling
- **Packaging:** npm

## 🛠️ Local Development Setup

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/smart-chef-ai.git
   cd smart-chef-ai
   ```

2. **Install the dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root of the project and add your Gemini API Key:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. Open [http://localhost:5173](http://localhost:5173) in your browser.
